Large Langauge models, leveraging its massive text corpora from various semantic sources such as web, documents, etc, have been used for guidance in task planning. In LLM-based guidnce, correctly applying action sequences should not only be feasible in LLM but also in the real life contexts. Therefore, state feedback is a key component tackling this problem. ProgPrompt is a pythonic programming language - like prompting technique consisting two parts: to generate task plan useful for robots and state feedback from environments leveraging LLM. 
  Some previous works have shown that LLM could be used as a guidance for task planning with void or lack of environment feedback. One particular work also leverages the same code-completion style planning, but ProgPrompt includes additional features: import - to represent feasible actions, natural langauge comments (#) for general guidance of planning. 
  Impressive points taken from this idea is that the prompt restricted the actions grounded to the current environments by import statements. Utilizing ViLD to detect objects in the scene and create the list for the prompt was another thing I learned.
