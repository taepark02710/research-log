Large Language Models, leveraging massive text corpora from various semantic sources such as websites and documents, have been used to guide task planning. In LLM-based guidance, correctly applying action sequences should not only be feasible within the language model but also in real-world contexts. Therefore, state feedback is a key component in addressing this problem. ProgPrompt is a Python-like prompting technique consisting of two parts: generating task plans for robots and incorporating state feedback from the environment using an LLM.

Some previous works have shown that LLMs can be used to guide task planning without environmental feedback. One particular work also leverages a code-completion style of planning, but ProgPrompt introduces additional features: import statements to represent feasible actions and natural language comments (#) to provide general planning guidance.

One impressive aspect of this idea is that the prompt restricts actions to those grounded in the current environment through import statements. Utilizing ViLD to detect objects in the scene and generate object lists for the prompt was another interesting idea that I learned from this work.

Throughout the experiments, the authors used various language models such as CODEX and GPT-3 to generate prompt-based task plans. I believe that selecting a capable language model that understands tasks in a programming-oriented format is crucial for achieving strong planning performance. Furthermore, under extreme environmental shifts, maintaining updated object lists and example prompts could become cumbersome.
